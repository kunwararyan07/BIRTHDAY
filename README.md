# Birthday Website 🎂

A birthday-themed website built using HTML, CSS, and JavaScript.

This project was created as a surprise birthday gift. It includes animations, a photo gallery, background music, and interactive sections to make the experience more memorable.

---

## Features

- Animated landing page
- Birthday countdown and welcome screen
- Photo gallery
- Background music with manual controls
- Birthday letter section
- Smooth scrolling animations
- Responsive design
- Confetti celebration effect
- Interactive buttons and hover effects

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/BIRTHDAY.git
```

Open the project folder and launch `index.html` in your browser.

No additional setup is required.

---

## Customization

You can personalize the website by updating:

- Photos inside the `assets/images` folder
- Background music inside `assets/music`
- Birthday message in the HTML file
- Colors and animations in `style.css`
